# 世界环境与环境交互

在渲染设置面板展开“世界环境”；也可在设置的“项目画面 → 渲染画面”或“渲染导出画面”中找到同一组控件。场景环境是场景级唯一配置，不作为可挂载到对象的组件。太阳和阴影、天空、全局雾气、海面和全局天气都在这里配置。

## 组件职责

环境系统采用“全局状态 + 对象交互组件”的分层：

- **世界环境设置**：太阳、天空、全局雾、海面、风雨雪雷暴和热浪的默认状态
- **局部风场**：定义局部风向、强度、影响范围、距离衰减和可选湍流
- **风力接收器**：挂在需要受风的对象上，控制是否接收全局风或局部风场、受力倍率、阻尼、柔韧度，以及是否传播给子对象
- **局部后处理覆盖**：只负责局部曝光、Bloom、阈值、半径和暗角，不负责全局环境、雾或天气
- **自动探针**：负责GI探针数据，不属于天气交互

旧的`mvoxel.volume`组件已从内置组件系统移除。它原先混合了全局环境、雾和后处理职责，现已拆分：全局环境回到场景环境设置，局部后处理使用“局部后处理覆盖”，风力交互使用“局部风场”和“风力接收器”。旧场景中的未知组件数据会继续保留，但不会再参与新建或运行时应用。

## 海面与实时动画

启用水面后可设置世界高度、颜色、波浪大小、波长、粗糙度、高光强度、动画速度、流向和细节扰动。水面通过实时着色器改变波相位与法线，随着帧号持续运动；它仍是无限水平面，不改变几何轮廓，也不模拟完整水下透视、岸线碰撞或水体物理。

## 风与天气

天气参数统一保存在场景级环境配置中。风力接收器是对象是否参与风场求解的声明，不会改变全局天气参数。当前天气画面效果仍以实时着色器为主，后续可在组件数据基础上接入体素模型形变、粒子碰撞、积水和积雪。

## MCP自动化

`render.settings.get`会返回水面动画与天气参数；`render.settings.set`支持写入`waterAnimationEnabled`、`waterAnimationSpeed`、`waterFlowX`、`waterFlowZ`、`waterDetailStrength`、`waterSpecularStrength`、`weatherWindStrength`、`weatherWindDirection`、`weatherRain`、`weatherSnow`、`weatherStorm`、`weatherHeatHaze`和`weatherLightning`。写入后会同步到当前场景级环境配置。对象组件的自动化读写将在组件命令接口接入后补充。
