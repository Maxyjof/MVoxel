# 世界环境

在渲染设置面板展开“世界环境”；也可在设置的“项目画面 → 渲染画面”或“渲染导出画面”中找到同一组控件。场景环境是场景级唯一配置，不作为可挂载到对象的组件。项目渲染画面与导出画面各自保存参数；“画面默认值”用于新项目初始值。太阳和阴影位于同一渲染设置中的“光照与阴影”。

“世界环境”包含地面、天空、太阳光、环境光、补光、雾气、海面和天气。雾浓度为零时关闭；起始距离控制雾从相机多远处开始，最大不透明度限制遮盖程度。距离雾目前在实时渲染中生效。

## 海面与实时动画

启用水面后可设置世界高度、颜色、波浪大小、波长、粗糙度、高光强度、动画速度、流向和细节扰动。水面通过实时着色器改变波相位与法线，随着帧号持续运动；它仍是无限水平面，不改变几何轮廓，也不模拟完整水下透视、岸线碰撞或水体物理。

## 风与天气

天气参数统一保存在场景级环境配置中：

- 风强度与风向：驱动雨雪条带方向、天气扰动和热浪扰动
- 降雨强度：显示风向推动的雨幕效果
- 降雪强度：显示受风向影响的雪花条带效果
- 雷暴强度：压暗天空并增强风暴氛围
- 雷电频率：驱动雷暴闪光变化
- 热浪折射散射：驱动屏幕空间热浪颜色扰动

当前天气效果是实时屏幕空间着色器效果，尚未等同于完整的体积云、粒子碰撞、地面积水、积雪、场景物体受风和动态点光源雷电系统。模板“季风暴雨”“雪原微光”“雷暴海湾”“灼热荒岸”提供对应默认环境组合，可从新建项目模板中直接选择。

## MCP自动化

编辑器自动化命令`render.settings.get`会返回水面动画与天气参数；`render.settings.set`支持写入以下字段：`waterAnimationEnabled`、`waterAnimationSpeed`、`waterFlowX`、`waterFlowZ`、`waterDetailStrength`、`waterSpecularStrength`、`weatherWindStrength`、`weatherWindDirection`、`weatherRain`、`weatherSnow`、`weatherStorm`、`weatherHeatHaze`和`weatherLightning`。写入后会同步到当前场景级环境配置。
