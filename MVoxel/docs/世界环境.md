# 世界环境与环境交互

通过渲染配置中的“环境配置…”或“窗口”菜单打开环境配置窗口，调整天空与地面、水面、全局雾气和天气。太阳和阴影在渲染配置的光照设置中调整。场景环境是场景级唯一配置，不作为可挂载到对象的组件。

## 组件职责

环境系统采用“全局状态 + 对象交互组件”的分层：

- **世界环境设置**：太阳、天空、全局雾、海面、风雨雪雷暴和热浪的默认状态
- **局部风场**：定义局部风向、强度、影响范围、距离衰减和可选湍流
- **风力接收器**：挂在需要受风的对象上，控制是否接收全局风或局部风场、受力倍率、阻尼、柔韧度，以及是否传播给子对象
- **局部后处理覆盖**：只负责局部曝光、Bloom、阈值、半径和暗角，不负责全局环境、雾或天气
- **自动探针**：负责GI探针数据，不属于天气交互

旧的`mvoxel.volume`组件已从内置组件系统移除。它原先混合了全局环境、雾和后处理职责，现已拆分：全局环境回到场景环境设置，局部后处理使用“局部后处理覆盖”，风力交互使用“局部风场”和“风力接收器”。旧场景中的未知组件数据会继续保留，但不会再参与新建或运行时应用。

## 雾气

环境窗口的"雾气"分组按基础、高度与分布、散射与光照、体积质量四组提供参数，全部写入场景级环境配置（`.mvox` 的 `environment`），并同步到项目渲染配置与渲染预设。每个控件的含义以悬停提示为准。

- 基础：雾颜色、雾浓度（消光系数 σt）、雾起始距离、天空混合、最大不透明度、内散射亮度。
- 高度与分布：雾层基准高度、高度衰减（密度按 `exp(-b·(y - 基准高度))` 衰减）、体积计算距离，以及密度起伏、噪声频率、噪声漂移（三维值噪声，随全局风与时间流动）。
- 散射与光照：Henyey–Greenstein 各向异性 g、单次散射反照率、太阳内散射强度与颜色、天空雾强度。
- 体积质量：实时体积采样步数，0 表示使用解析高度雾积分。

三条渲染路径共用同一组参数，但计算方式不同：

| 路径 | 雾的计算 |
| --- | --- |
| 实时渲染 | 沿主射线对指数高度密度做解析积分，零噪声、零额外采样；步数大于 0 时改为逐像素固定抖动的体积步进，逐点查询太阳阴影形成体积光柱。天空与背景按天空雾强度融入雾色。 |
| 路径追踪 | 把雾当作参与介质：每个弹射段按 Beer–Lambert 透射率衰减 throughput，并按透射率分布采样一个散射位置，累加天空环境内散射与被几何遮挡的太阳内散射。间接光、自发光与镜面反射穿过雾时同样衰减。 |
| 硬件光追旁路 | 只输出基色，但按同一解析公式应用距离/高度雾与太阳内散射，保证切换渲染方式时雾不消失。 |

后续改进项与每轮验证流程见`Docs/雾气系统路线图.md`。

场景视口始终关闭雾。旧项目缺少新字段时按默认值加载（均匀雾、无噪声、解析积分），画面与升级前基本一致，并额外获得太阳方向内散射。体积步进与路径追踪的散射点会查询几何阴影，浓雾搭配高步数会增加渲染开销。

## 海面与实时动画

半透明体素水池与无限海面是两种不同的表示。体素水体按材质折射率和吸收参数透射；水体与池底相接时，射线连续穿过实际所在盒体，避免在合并盒交界处生成假的空气缝和黑线。

启用水面时默认开启动画，可手动关闭；可以设置世界高度、颜色、波浪大小、波长、粗糙度、高光强度、动画速度、流向和细节扰动。多方向波纹随时间运动。路径追踪动态预览会定期重置累积，截图采样期间固定水面时刻；水面仍是无限水平面，不改变几何轮廓，也不模拟完整水下透视、岸线碰撞或水体物理。

## 风与天气

时间轴有未保存修改时，关闭时间轴窗口、切换或重载时间轴、关闭或切换项目、退出编辑器都会先询问是否保存，并可选择“保存”“另存为…”或“不保存”；取消会保留当前项目与时间轴。窗口内的“另存为…”会把当前内容存成 Assets 内的新资产，原资产保持不变，时间轴名称取新文件名。

渲染窗口的“导出”可选择视频，使用当前时间轴（也可以是尚未保存的临时时间轴）或已保存的时间轴资产。输出帧率可调整，时长由时间轴决定。选择 MP4 路径后，程序先在后台准备可取消的体素与动画快照，再逐帧渲染并通过 Windows Media Foundation 编码 H.264；准备期间若场景发生变化会中止并提示重新导出。宽高必须为偶数，同一路径不允许同时存在两条视频任务。导出队列可取消渲染或编码；取消排队中的视频帧会中止整条视频，不会留下半条帧链。编码先写入带点前缀的临时文件，确认文件存在且非空后才提交为目标路径，因此空文件或半成品不会被当成成片；编码失败或取消会删除临时文件并保留帧序列供再次编码，全部成功后自动删除中间帧目录。编码期间目标路径被占用时保留成片并提示其位置。为防止覆盖，目标视频必须使用不存在的文件名。

对象启用轨道和动画片段轨道在播放、暂停和拖动播放头时参与视口预览。预览使用独立场景状态，不将采样结果写入编辑中的场景；引用的动画片段或体素快照缺失、损坏时会提示并回退显示编辑场景。可在动画窗口插入位置和旋转关键帧。格点体素模型的位置按体素格取整，旋转按 90 度格点朝向逐帧切换；自由变换对象的旋转在关键帧之间插值。格点模型的缩放动画尚未实现。

天气参数统一保存在场景级环境配置中，可在环境窗口的“天气”中调整。天气种子改变雨雪、闪电和热浪的随机分布。打开时间轴窗口即可使用临时时间轴预览天气，无需先创建资产；空时间轴默认 30 帧/秒、总时长 10 秒，可分别调整帧率、总时长和总帧数，改动帧率会按当前秒数换算总帧数。播放、暂停和拖动播放头可控制天气，暂停或关闭窗口后保持当前帧。仅播放、暂停或移动播放头不会使时间轴变为未保存状态。更改时间轴内容后关闭窗口会询问是否保存；首次保存时选择项目 Assets 内的位置，取消选择会保留窗口和修改。可以在轨道中选择场景对象和动画片段。视频导出按输出帧取样天气、水面和对象轨道，采样使用入队时的场景、体素、动画片段和体素快照副本；选定的场景相机也按轨道采样。截图和静态导出固定入队时刻。雨雪使用世界坐标粒子场，风和时间决定其位置，表面深度限制粒子可见范围；“雨雪可见距离”控制计算范围，默认 128 世界单位。雷暴亮度是画面近似；热浪在渲染视图使用随时间变化的屏幕空间位移，场景基础预览使用轻微色偏，两者都不是物理折射。热浪使用原始累积图的位移差，低样本路径追踪可能显露噪点。视线深度遮挡不等于屋檐遮雨，天气尚不模拟粒子碰撞、积水或积雪。风力接收器是对象是否参与风场求解的声明，不会改变全局天气参数。

## 积水与积雪投射

在场景中选择对象，通过检查器的“添加组件 → 环境交互”添加“积水投射”或“积雪投射”。选中对象时场景视口显示投射盒线框；投射盒随对象的位置、旋转及缩放变化，局部 Y 轴是投射深度方向。将盒子覆盖需要处理的表面，并在检查器设置范围、偏移、强度、边缘和深度淡化、表面角度、覆盖图案、颜色、粗糙度、法线扰动及叠加顺序。各参数含义可悬停查看。

投射改变投射盒内表面的材质响应，不会生成真实积水体积或积雪厚度；水面不接收投射。角度开始和结束相同时使用硬阈值，例如两者均为 0° 时只接收正对投射方向的表面。接收图层可选择全部、无或指定图层；解析地面不属于对象图层，仅选择全部时接收投射。雨雪不会自动产生或累积这些投射组件，需要手动放置和调整。功能与画面表现仍待实际验收。

## MCP自动化

`editor.captureView` 可在单次截图指定 `rain`、`snow`、`heatHaze`、`storm`、`lightning`、`weatherSeed`、`weatherViewDistance` 和 `weatherTime`（秒）；省略时沿用场景参数和当前时间轴时刻。这些截图覆盖值不写入场景。`editor.captureStatus` 的元数据记录实际天气参数及固定时刻，便于比较。

`render.settings.get`会返回水面动画、天气与雾气参数；`render.settings.set`支持写入`waterAnimationEnabled`、`waterAnimationSpeed`、`waterFlowX`、`waterFlowZ`、`waterDetailStrength`、`waterSpecularStrength`、`weatherWindStrength`、`weatherWindDirection`、`weatherRain`、`weatherSnow`、`weatherStorm`、`weatherHeatHaze`、`weatherLightning`、`weatherSeed`和`weatherViewDistance`，以及`fogHeight`、`fogHeightFalloff`、`fogAnisotropy`、`fogSunScatterStrength`、`fogSunScatterColor`、`fogAlbedo`、`fogInscatterStrength`、`fogSkyFogStrength`、`fogVolumetricSteps`、`fogViewDistance`、`fogNoiseStrength`、`fogNoiseScale`、`fogNoiseSpeed`。写入后会同步到当前场景级环境配置。

对象组件自动化接口：`scene.components.get`读取对象上的局部后处理覆盖、局部风场、风力接收器、积水和积雪投射；`scene.components.set`可按字段创建或更新这些组件。`windReceiver`支持`receiveGlobalWind`、`receiveLocalWind`、`includeChildren`、`forceScale`、`drag`和`flexibility`，`windField`支持`direction`、`strength`、`range`、`falloff`和`turbulence`。`puddleDecal`和`snowDecal`支持投射范围、偏移、角度、覆盖率、颜色、粗糙度及排序等组件字段；`receiverLayers`是 32 位无符号图层掩码，全部图层为 `4294967295`。

时间轴与视频导出也可由自动化完成：`timeline.set`整体写入并可选保存，`timeline.update`改帧率、总时长或增删三类轨道，`timeline.state`读窗口状态，`timeline.seek`按帧或秒定位播放头，`timeline.play`与`timeline.pause`控制预览，`timeline.validate`用与导出相同的一套判定检查轨道完整性。`video.export`按时间轴入队导出 MP4，`video.status`读取准备、渲染、编码、完成、失败与取消状态及帧进度，`video.cancel`按路径取消整条任务。`editor.captureView`额外支持`timelinePath`与`timelineFrame`，按指定时间轴帧应用对象轨道并把天气时刻对齐到该帧。

组件字段按对象递归合并：例如只写入 `puddleDecal.size.x` 会保留原来的 `size.y` 和 `size.z`；数组及非对象值则整体替换。
