# 世界环境

在渲染设置面板展开“世界环境”；也可在设置的“项目画面 → 渲染画面”或“渲染导出画面”中找到同一组控件。项目渲染画面与导出画面各自保存参数；“画面默认值”中的对应设置用于新项目初始值。场景窗口使用独立的基础预览，不显示水面或雾。太阳和阴影位于同一渲染设置中的“光照与阴影”。HDR/EXR 环境贴图在选中环境资产后的检查器中设置或清除。

“世界环境”包含地面显示、颜色与地平线过渡，程序化天空颜色、环境光和补光，以及雾和水面。雾浓度为零时关闭；起始距离控制雾从相机多远处开始，颜色权重在天空色与雾颜色之间混合，最大不透明度限制遮盖程度。距离雾目前仅在实时渲染中生效。

水面默认关闭。启用后可设置世界高度、颜色、波浪大小、波长及粗糙度。水面是无限水平面，波浪通过静态法线波纹表现，不改变几何轮廓；水面不透明，不模拟折射或水下透视。实时与路径追踪均可看到水面，水面与体素按距离遮挡。
