# 世界环境与环境交互

在渲染设置面板展开“世界环境”；也可在设置的“项目画面 → 渲染画面”或“渲染导出画面”中找到同一组控件。场景环境是场景级唯一配置，不作为可挂载到对象的组件。太阳和阴影、天空、全局雾气、海面和全局天气都在这里配置。

## 组件职责

环境系统采用“全局状态 + 对象交互组件”的分层：

- **世界环境设置**：太阳、天空、全局雾、海面、风雨雪雷暴和热浪的默认状态
- **局部风场**：定义局部风向、强度、影响范围、距离衰减和可选湍流
- **风力接收器**：挂在需要受风的对象上，控制是否接收全局风或局部风场、受力倍率、阻尼、柔韧度，以及是否传播给子对象
- **局部后处理覆盖**：只负责局部曝光、Bloom、阈值、半径和暗角，不负责全局环境、雾或天气
- **自动探针**：负责GI探针数据，不属于天气交互

旧的`mvoxel.volume`组件已从内置组件系统移除。它原先混合了全局环境、雾和后处理职责，现已拆分：全局环境回到场景环境设置，局部后处理使用“局部后处理覆盖”，风力交互使用“局部风场”和“风力接收器”。旧场景中的未知组件数据会继续保留，但不会再参与新建或运行时应用。

## 雾气

环境窗口的"雾气"分组按基础、高度与分布、散射与光照、体积质量四组提供参数，全部写入场景级环境配置（`.mvox` 的 `environment`），并同步到项目渲染配置与渲染预设。每个控件的含义以悬停提示为准。

- 基础：雾颜色、雾浓度（消光系数 σt）、雾起始距离、天空混合、最大不透明度、内散射亮度。
- 高度与分布：雾层基准高度、高度衰减（密度按 `exp(-b·(y - 基准高度))` 衰减）、体积计算距离，以及密度起伏、噪声频率、噪声漂移（三维值噪声，随全局风与时间流动）。
- 散射与光照：Henyey–Greenstein 各向异性 g、单次散射反照率、太阳内散射强度与颜色、天空雾强度。
- 体积质量：实时体积采样步数，0 表示使用解析高度雾积分。

三条渲染路径共用同一组参数，但计算方式不同：

| 路径 | 雾的计算 |
| --- | --- |
| 实时渲染 | 沿主射线对指数高度密度做解析积分，零噪声、零额外采样；步数大于 0 时改为逐像素固定抖动的体积步进，逐点查询太阳阴影形成体积光柱。天空与背景按天空雾强度融入雾色。 |
| 路径追踪 | 把雾当作参与介质：每个弹射段按 Beer–Lambert 透射率衰减 throughput，并按透射率分布采样一个散射位置，累加天空环境内散射与被几何遮挡的太阳内散射。间接光、自发光与镜面反射穿过雾时同样衰减。 |
| 硬件光追旁路 | 只输出基色，但按同一解析公式应用距离/高度雾与太阳内散射，保证切换渲染方式时雾不消失。 |

后续改进项与每轮验证流程见`Docs/雾气系统路线图.md`。

场景视口始终关闭雾。旧项目缺少新字段时按默认值加载（均匀雾、无噪声、解析积分），画面与升级前基本一致，并额外获得太阳方向内散射。体积步进与路径追踪的散射点会查询几何阴影，浓雾搭配高步数会增加渲染开销。

## 海面与实时动画

半透明体素水池与无限海面是两种不同的表示。体素水体按材质折射率和吸收参数透射；水体与池底相接时，射线连续穿过实际所在盒体，避免在合并盒交界处生成假的空气缝和黑线。

启用水面时默认开启动画，可手动关闭；可以设置世界高度、颜色、波浪大小、波长、粗糙度、高光强度、动画速度、流向和细节扰动。多方向波纹随时间运动。路径追踪动态预览会定期重置累积，截图采样期间固定水面时刻；水面仍是无限水平面，不改变几何轮廓，也不模拟完整水下透视、岸线碰撞或水体物理。

## 风与天气

天气参数统一保存在场景级环境配置中，可在环境窗口的“天气”中调整。实时渲染和路径追踪均显示屏幕空间雨雪及雷暴，截图时固定天气时刻；热浪目前只是颜色近似，不是折射。风力接收器是对象是否参与风场求解的声明，不会改变全局天气参数；天气不模拟粒子碰撞、积水或积雪。

## MCP自动化

`render.settings.get`会返回水面动画、天气与雾气参数；`render.settings.set`支持写入`waterAnimationEnabled`、`waterAnimationSpeed`、`waterFlowX`、`waterFlowZ`、`waterDetailStrength`、`waterSpecularStrength`、`weatherWindStrength`、`weatherWindDirection`、`weatherRain`、`weatherSnow`、`weatherStorm`、`weatherHeatHaze`和`weatherLightning`，以及`fogHeight`、`fogHeightFalloff`、`fogAnisotropy`、`fogSunScatterStrength`、`fogSunScatterColor`、`fogAlbedo`、`fogInscatterStrength`、`fogSkyFogStrength`、`fogVolumetricSteps`、`fogViewDistance`、`fogNoiseStrength`、`fogNoiseScale`、`fogNoiseSpeed`。写入后会同步到当前场景级环境配置。

对象组件自动化接口：`scene.components.get`读取对象上的局部后处理覆盖、局部风场和风力接收器；`scene.components.set`可按字段创建或更新这些组件。`windReceiver`支持`receiveGlobalWind`、`receiveLocalWind`、`includeChildren`、`forceScale`、`drag`和`flexibility`，`windField`支持`direction`、`strength`、`range`、`falloff`和`turbulence`。
