# 脚本与插件升级执行清单

本清单记录代码审查后的执行顺序；未勾选项尚未实现或验收。

- [x] 插件包安装检查全部文件均列入 SHA-256 清单，并校验每个文件。
- [x] 更新插件时先保留旧目录，切换失败时尝试恢复；清理失败保留备份并记录日志。
- [x] 自动恢复失败时保留备份并报告其路径；暂存目录清理失败不会覆盖原始安装错误。
- [x] 按依赖顺序激活插件；依赖诊断失败或依赖激活失败时跳过依赖方，并记录原因。
- [x] 识别内置插件声明的项目及插件管理权限，过滤空扩展 ID 和名称。
- [x] 激活阶段发生异常时回滚该插件已注册的扩展，避免残留入口。
- [x] 目录安装和打包拒绝插件目录内的链接；打包先检查清单和入口，并在完成后替换目标文件。
- [x] 插件发现跳过安装暂存、备份及链接；单个目录读取失败时记录日志并继续发现其他插件。
- [x] 生成器整数参数按控件支持范围校验，默认值和运行值统一归一化；包围盒坐标转换前检查范围。
- [x] 限制 Lua 生成器声明和插件返回值的表嵌套深度，避免循环表导致宿主无限递归。
- [x] 生成器所有暂存写入检查包围盒，区域预算允许重复覆盖已有暂存格，换色读取暂存结果。
- [x] 增加编辑器内生成器 API 与使用说明。
- [x] 刷新生成器声明时按类型与新范围更新已有参数；切换生成器不沿用其他资产的参数。
- [x] 为 JavaScript 和 Lua 生成器增加 `getVoxel`，支持读取目标体素和本次暂存结果。
- [x] 增加 `setVoxelData`，可将读取到的完整 RGBA、材质槽和标志写回，包括零 Alpha 数据。
- [x] 生成器写入保留原生体素的完整标志字节，避免复制或换色时拒绝未知标志位。
- [x] 补充插件开发指南，说明当前注册接口、无状态调用与面板限制；修正占位面板提示。
- [x] 提供可复制编辑的噪声丘陵与颜色斑驳内置脚本，分别覆盖程序化地形和颜色纹理工作流。
- [x] 增加基于原始邻域状态的表面保留脚本，清除处理范围内的内部体素。
- [x] 内置模板支持设置处理中心，使操作不局限于对象原点附近。
- [x] 增加按 RGB 批量换色模板，保留原有透明度、材质槽和标志。
- [x] 源码修改后要求重新解析声明并检查参数，防止参数面板与实际执行源码不一致。
- [x] 生成器存在未保存源码时阻止切换或新建，并提供恢复已保存版本的明确入口。
- [x] 关闭、切换项目及退出时将生成器草稿纳入保存提示；另存项目先保存草稿。
- [x] 项目切换完成时重置生成器资产和参数，避免旧项目路径被误用于新项目。
- [x] 生成器宿主批量遍历定期检查运行时限，超时丢弃暂存结果。
- [x] Lua 生成器的宿主回调检查数值参数类型和数量，防止缺参或错误类型被当成零。
- [x] JavaScript 生成器接口显式检查坐标、体素数据与颜色数组，避免隐式类型转换。
- [x] Lua 可选材质参数仅在省略时回退，颜色数值及通道与 JavaScript 一致地检查和截断。
- [x] 生成器绘制和换色检查打包颜色范围，明确普通绘制与完整体素数据写入的 Alpha 语义。
- [x] 生成器参数表格式错误时报告声明错误，Lua 空表仍可表示无参数。
- [x] 依赖版本比较补齐缺省分量，修正 `^0.0` 的边界并避免计算上限时整数溢出。
- [x] 依赖版本声明按匹配器支持的语法校验，拒绝无法解析的范围。
- [x] 插件菜单与自动化状态提供最近一次启动结果，区分依赖、权限和脚本启动失败。
- [x] JavaScript 插件注册接口显式提供与 Lua 一致的小写名称，并兼容首字母大写的调用。
- [x] 插件面板支持注册自定义说明文本，JavaScript 和 Lua 内置示例已更新。
- [x] 插件面板自动提供所属插件的命令按钮，并沿用插件菜单的执行与错误处理。
- [x] 插件面板显示最近一次菜单或面板命令的结果和错误。
- [x] 插件面板提供 JSON 参数输入，可调用需要参数的插件命令并显示解析错误。
- [x] 允许从项目启用清单中禁用缺失插件，并拒绝安装占用内置插件 ID 的外部包。
- [x] 启停操作遇到损坏、未知版本或无效 ID 的项目清单时拒绝写入并保留原文件。
- [x] 插件菜单提供项目插件启停和缺失插件禁用入口，悬停显示插件 ID 与版本。
- [x] 单次插件激活共用安装与启用清单快照，避免重复扫描造成诊断与启动依据不一致。
- [x] 插件菜单提供 `.mvplugin` 文件安装入口，安装与项目启用分开管理。
- [x] 插件菜单提供目录打包入口，使用原生目录和保存对话框。
- [x] 插件包解压前检查条目数及声明的解压总大小；打包也检查对应资源上限。
- [x] 解压过程中核对实际大小和目标路径，限制校验清单大小，并在暂存清理失败时保留原错误。
- [x] 打包时对写入压缩包的同一数据流计算校验值，避免二次读取造成内容和摘要不一致。
- [x] 插件入口调用阶段再次校验自动化和编辑器命令权限；拒绝调用时更新状态并记录日志。
- [ ] 完成插件生命周期、依赖顺序、失败隔离与权限边界的端到端审查，修复发现的问题。
- [ ] 完成生成器声明解析、参数、执行预算、暂存和撤销路径的审查，改进诊断与使用体验。
- [ ] 检查插件安装包的资源限制、目录链接和异常处理，完善安装及打包边界。
- [ ] 完善脚本 API、插件清单、权限、示例与故障排查文档，并根据实际实现同步更新。
- [ ] 参考开放源码体素编辑器的脚本参数与常用生成工具，设计并实现适合 MVoxel 的扩展能力。
- [x] 完成 Release 编译；功能和交互交由项目所有者验收。

每次修改后更新对应条目和使用文档，执行 Release 编译与 `git diff --check`；按项目约定不运行自动化测试。完成实现不等同于用户验收。

SHA-256 清单用于发现文件内容不一致，不能证明插件作者身份；安装和启用前应确认来源可信。
