# Light BVH 评估与人工验收

## 当前结论

本轮落地均匀发光面 NEE 与 balance heuristic MIS，暂不引入 Light BVH。这个判断是基于已实现管线的工程评估，不是性能实测结论：目前没有用户场景的帧时间、方差和收敛比较数据，不能证明增加树遍历与维护能够获益。光源树与几何 BVH 没有架构冲突，适合作为多处小光源场景的后续候选。

均匀采样每个表面顶点只选一个面、最多投射一条直连遮挡射线，选面成本 O(1)；BSDF 命中发光面的反向概率查询是 O(log F)，F 为目录面数。GPU 面记录为 32F+16 字节（分配容量向上取整），不保存光源树。CPU 已按脏区及六邻区提取面，但排序、打包与上传仍针对整个目录；密集发光体编辑的同步开销是下一项需要观察的成本。无需为无发光内容的场景引入逐帧建树。

Light BVH 的主要价值应是按接收点选择更有贡献的光源、降低采样方差，而非把目前 O(1) 的选面变得更快。大范围分散灯光、近亮远暗混合有获益可能；强遮挡仍会浪费样本，因为普通光源树不预测可见性。少量发光面通常不值得支付树和反向 PDF 遍历的成本。若需引入，应保留当前均匀路径作为可比较基线。

## 已实现与范围

- 目录来自完整世界，保留 64 位整数世界坐标；上传时转为工作集锚点相对整数坐标。仅收集不透明发光体邻格为空的单位面；不依赖几何贪心合并或砖池预留间隙。
- 每个面的原始颜色和材质槽保留；发光强度在 Shader 中读取，不按亮度阈值删除暗弱灯。
- 每次直接采样使用 P(face)=1/F、面内均匀面积采样以及距离平方/灯面余弦的立体角转换。
- 使用完整 GGX/余弦混合 BSDF PDF，NEE 与反弹命中使用同一 PDF 评估。终止弹射只使用直接估计，不额外降低其权重；镜面粗糙度保持非零下限。
- 直接连接遇到透明体也判遮挡；经过透明介质的路径清除上一顶点的竞争 PDF，由原有介质路径贡献发光。直接可见灯面及不在目录中的灯面保留完整命中贡献。
- 两条估计使用相同发光钳制；最终辐射度钳制仍有偏，因此不宣称整个渲染器严格无偏。
- 手动 LOD/预算路径不建立完整世界的采样目录，以避免几何与灯面不一致。自发光照明选择 Compute；硬件 RT 的基础色路径不承担该照明。
- 世界实例变化全量刷新；增量修改同时刷新邻区。材质变化清空累积。空目录绑定有效零头缓冲，容量增长等待设备空闲后重新分配；不删除用户数据。

## 人工验收步骤

所有运行结果由用户记录，本轮没有运行自动化测试、烟测或性能台架。固定 GPU/驱动、窗口分辨率、相机、采样数、反弹数和所有材质参数。先关闭快速降噪与辉光观察采样，再恢复同样的后期设置比较最终画面。只切换“发光面直接采样”，每次等待累积重新开始。

| 场景/动作 | 观察与记录 |
| --- | --- |
| 空世界、无发光体 | 不应出现额外照明；目录为零，不读取无效面 |
| 单个小发光体照亮墙面 | 比较同样 16、64、256 样本的噪声和亮度，不把单帧耗时当收敛速度 |
| 多处彩灯、近灯与远灯、暗弱灯 | 记录灯数、面数、帧时间及达到可接受画质的时间；判断均匀分布是否明显浪费样本 |
| 完全挡住灯、贴面灯、凹角与薄墙 | 不应因 NEE 穿墙；观察自相交和接触处亮斑 |
| 玻璃前后、半透明发光体 | 直连不应穿越介质；反弹路径仍应保留介质后的发光 |
| 漫反射、粗糙镜面、金属、1次与多次反弹 | 两种采样方式的高样本结果应趋近；检查终止弹射及镜面亮度 |
| 跨区块绘制/删除灯或遮挡体、撤销/重做 | 相邻灯面同步变化；没有已删除灯继续照明 |
| 改颜色、材质槽、发光倍率、开关自发光 | 累积重新开始；材质改变不使用过期发光值 |
| 切换图层、项目、相机与导出 | 同样设置具有一致光源集合；实时模式保持确定性行为 |

记录硬件、场景、面数、索引同步 CPU ms、帧时间、采样数和截图。性能面板中的“索引同步”包含提取、排序、打包和上传，不是 GPU 时间；本轮未添加 GPU 阶段计时，不能把帧时间差直接归因于某一条射线或 Shader。

## 满足条件后如何接入 Light BVH

若以上比较显示大量远处或低贡献灯面占用了主要样本预算，且直接采样是当前收敛瓶颈，再实现：按空间 brick 聚合面记录；节点保存包围盒、面积和功率；接收点加权遍历时累乘精确分支概率；BSDF 命中查询重建同一概率。必须为低权重节点保留非零选择概率，不以裁掉弱光换取稳定性。

几何 BVH 继续负责遮挡。材质和相邻遮挡编辑要使光源权重及面记录失效；面变化更新叶子和祖先，结构变化重建。加入树后还需重复人工比较，若更新/遍历成本超过收敛收益则保留均匀方案。当前没有引入 ReSTIR、可见性复用或分辨率缩减。
