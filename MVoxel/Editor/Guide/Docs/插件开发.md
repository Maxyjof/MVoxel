# 插件开发

## 创建与启用

插件目录包含 `package.json` 和 JavaScript（`.js`）或 Lua（`.lua`）入口。内置 Lua 示例位于程序目录的 `Plugins/com.mvoxel.lua-sample`，包含清单和完整入口。插件安装在编辑器级目录，启用状态属于当前项目；依赖必须安装且启用，启动时依赖先于依赖方。
使用“插件 → 安装插件包…”选择 `.mvplugin` 文件可安装或更新编辑器级插件；安装后项目中的启用状态保持不变。更新已启用插件时，当前项目会重新加载插件。
更新失败时会尝试恢复旧版本；若自动恢复也失败，错误信息和日志会给出保留的备份目录，请先保留该目录并检查目标位置。
使用“插件 → 打包插件目录…”选择包含 `package.json` 的目录，再选择源目录之外的输出位置，可生成带逐文件校验清单的分发包。
打包时校验值根据实际写入包中的文件内容计算；打包失败时不会替换已有输出文件。
分发包最多包含 10000 个条目，解压总大小不超过 1 GiB；打包时源文件最多 9999 个、总大小不超过 1 GiB。资源较大的数据应由项目资产管理。
解压时还会检查实际写入的大小与目标路径；校验清单不超过 8 MiB。
内置插件 ID 保留给程序自身，不能安装同 ID 的外部插件。打开项目后可在“插件 → 管理项目插件”启用、禁用已安装插件，或禁用项目清单中缺失的插件；如仍被其他已启用插件依赖，需先处理依赖方。启用时会同时启用已安装且版本符合要求的依赖。
项目插件启停清单损坏、版本不受支持或含无效 ID 时，启停操作会报错并保留原文件；修复清单后再重试。

清单的 `id` 是稳定标识，`name` 是显示名，`version` 是数字版本，`main` 是相对于插件目录的入口路径；`permissions` 是权限字符串数组，`dependencies` 是插件 ID 到版本范围的对象。支持精确版本、`*`、`1.*`、`1.2.*`、比较运算符以及 `^`、`~` 范围。插件 ID 应使用独立命名空间，避免冲突。
数字版本缺省的后续分量按 0 比较，例如 `1.2` 与 `1.2.0` 等价；当前不支持预发布版本标识。
多个比较条件可用空格或逗号组合，备选范围可用 `||` 分隔；无法解析的范围会在读取插件清单时报告错误。

## 注册扩展

入口定义 `activate(host)`，可按声明的权限注册：
JavaScript 和 Lua 均使用以下小写开头的接口名称；JavaScript 也兼容首字母大写的写法。

- `host.registerAutomation(id, name)`：需要 `automation.register`。
- `host.registerCommand(id, name)`：需要 `editor.command`，命令出现在插件菜单。
- `host.registerPanel(id, name, content)`：需要 `editor.panel`；可选的 `content` 为面板说明文本，最多 4096 字符，省略时显示默认提示。面板自动显示该插件已注册命令的按钮；当前不支持其他自定义控件。
- `host.registerComponent(id, name, category, defaultDataJson)`：需要 `scene.component`，组件 ID 须包含点号，默认数据是 JSON 文本。

注册自动化或命令后，分别实现 `runAutomation(id, payload)` 或 `runCommand(id, payload)`，返回可序列化的数据。每次调用都创建新的脚本环境并重新执行入口，不能依赖上一次调用保存在脚本全局变量中的状态。菜单命令使用空对象参数；面板中的输入框可填写 JSON，按钮使用该输入，格式错误时不会执行命令。传入和返回的 JSON 各有 1 MiB 字符限制；面板输入框最多 65535 字节，Lua 返回表不能循环引用或嵌套过深。运行时在调用阶段会再次核对对应的 `automation.register` 或 `editor.command` 权限；权限缺失时拒绝执行并记录启动状态和日志。
通过菜单或面板运行命令后，所属插件面板显示最近一次结果或错误；较长结果只显示前 4096 个字符。重新加载插件或切换项目会清除显示记录。

当前脚本运行时提供的是注册与数据交换接口，并不直接向脚本暴露通用文件系统、网络或编辑器对象。声明权限本身不会创建额外 API。插件启动或依赖失败时查看日志；启动失败会撤销本次注册。分发包的 SHA-256 用于检查内容一致性，不能验证作者身份，应确认来源可信。
在“插件 → 启动状态”中将鼠标悬停在插件 ID 上，可查看最近一次启动结果；详细日志可用于排查脚本错误和扩展 ID 冲突。
插件启动时使用一次读取的安装与启用状态；更换插件文件或更改清单后应重新加载插件。

## 分发与故障排查


安装 `.mvplugin` 时会检查包内每个文件是否列入校验清单并验证 SHA-256。校验用于检查内容一致性，不能证明作者身份，请确认插件来源可信。更新已安装插件时会暂存旧版本；如果切换失败会尝试恢复，无法清理的备份路径会记录在日志中。
插件按依赖顺序启动；依赖缺失、版本不匹配或启动失败时，依赖它的插件会跳过启动，具体原因记录在日志中。
插件启动过程中发生异常时，该插件本次注册的命令、面板、组件和自动化入口会被清除。
从目录安装或打包时，插件目录不能包含符号链接或其他重解析点；分发包须输出到插件源目录之外。打包会先检查插件清单和入口文件，成功后才替换目标文件。
插件发现会跳过安装过程遗留的暂存目录、备份目录和链接；无法读取的目录会记录日志，不影响发现其他插件。
生成器的整数参数使用 32 位整数；`min`、`max` 必须在该范围内且包含至少一个整数。默认值与运行值会按范围约束，未指定默认值时也会执行相同约束。
Lua 生成器声明和插件返回值应使用有限嵌套且无循环引用的表；超过嵌套限制会报告错误。
