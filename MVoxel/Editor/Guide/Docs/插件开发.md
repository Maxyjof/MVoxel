# 插件开发
## 安装和启用
1. 通过“插件 > 安装插件包…”选择 .mvplugin 文件。
2. 打开项目，在“插件 > 管理项目插件”启用插件。依赖也需要安装并启用。
3. 在插件菜单运行已注册的命令；出错时查看“插件 > 启动状态”和日志。
## 制作插件
插件目录包含 package.json 和 JavaScript 或 Lua 入口。可参考程序目录 Plugins/com.mvoxel.lua-sample。
通过“插件 > 打包插件目录…”生成分发包，输出位置须在源目录之外。
> 插件安装在编辑器中，启用状态属于当前项目。校验只能检查文件一致性，不能证明作者身份。接口、权限和限制见“参考资料/插件开发.md”。
