# 对象与图层
## 创建和调整
1. 在层级空白处右键创建对象；点击对象即可选择。
2. 在检查器的“变换”中调整位置、旋转和缩放；体素旋转以 90 度为单位。
3. 在检查器底部点击“添加组件”，可搜索并添加相机、光照等组件。
选中模型时，黄色轮廓标示其可见边界；后方物体不会截断轮廓，前方遮挡物不显示穿透描边。

## 控制显示
场景工具栏的图层控制编辑视图；相机组件的图层遮罩控制相机画面，两者分别设置。
重叠模型的显示顺序由模型组件的排序图层和排序顺序决定。隐藏父对象也会隐藏子对象。
> 锁定对象可避免在场景中误选；在层级选择其他对象会解除原锁定。

## 曲线渲染器

层级右键「创建曲线渲染器」，或给空对象添加同名组件。它用一条贝塞尔曲线生成体素，曲线随时可改，体素跟着重建。

1. 检查器点「进入曲线编辑」，场景里出现控制点、入/出切线和朝向手柄。
2. 拖动控制点改走向；拖切线方块改弯曲角度；拖「朝向」改方形、十字截面的旋转。
3. 双击曲线插入控制点，选中后按 Delete 删除；也能在检查器的点列表里改位置、角度和宽度倍率。
4. 「生成体素」里改形状、半径、采样间距、颜色和排序图层，体素即时重建。

生成的体素保存在场景文件里，不会出现在检查器，也不能进入绘制模式；想改形状只能改曲线或生成参数。曲线渲染器和模型组件不能挂在同一个对象上。

## 树生成器

层级右键「创建树生成器」，或给空对象添加同名组件。它用一组参数程序化生成一棵树，风格、树干、枝条、树冠和颜色都可以调。

1. 先在「风格」里选一个方向，组件会套用该风格的推荐参数。
2. 调树干、枝条、树冠和颜色；参数改动不会自动生效。
3. 点「生成体素」替换当前的树，不满意就接着调再点一次。
4. 满意后点「实例化为体素模型」，组件变成模型组件，这时才能进入绘制模式。

实例化之后不能再把模型变回树生成器，只能按 Ctrl+Z 撤销。生成的体素同样保存在场景文件里，检查器看不到，也不写入项目资产。

## 调整面板布局

拖动面板标签或标题：贴近目标面板边缘时预览分区，拖到顶部标签栏或标题栏时合并为标签。正文区域不触发停靠，可自由移动窗口；松开鼠标时仅应用当前显示的预览。没有五向停靠方格。教程和图片预览保持独立浮动。

浮动窗口的边缘和底部带有阴影，便于与停靠面板区分。

“编辑”菜单可聚焦、隐藏或显示、锁定或解锁选中对象，也可创建子对象或取消选择。
