# 对象与图层

## 管理对象

- 在层级空白处右键创建对象；右键对象可查看管理操作。
- 检查器的“变换”可调整位置、旋转和缩放。体素旋转以 90 度为单位。
- 模型可以重叠；重叠位置按模型组件的排序图层和排序顺序显示。

## 图层

- 场景工具栏的“图层”只控制场景视图。
- 相机有独立的图层遮罩，用于控制相机画面。

- 每个对象固定包含一个变换组件。相机和光照组件在同一对象上不能重复添加。

- 锁定对象后，场景中不能选择其他对象；在层级选择其他对象会自动解除原锁定。通过停靠面板右上角的菜单可添加检查器标签，各检查器可独立锁定对象。

- 在停靠面板右上角的三点菜单中，按常规、渲染或工具分类添加窗口标签；顶部“窗口”菜单用于打开或聚焦已有窗口。

- 停靠面板即使只有一个窗口，也会显示窗口名称标签和右侧菜单。

使用选择工具点击体素时会选中它所属的对象，场景视图以高亮轮廓显示该对象；在层级中选择模型也会显示轮廓。

层级中隐藏的对象（含被隐藏父对象或图层影响的对象）名称会变淡；选中模型时显示可见外轮廓。

场景中点击对象时，层级会展开其父级并定位选中项；选中父对象时，场景轮廓包括可见的子对象。

场景选择描边由显卡根据视口像素生成对象及可见子对象的遮罩，再合成可见轮廓；不会降低视口分辨率。

GPU 选择描边使用标准 Vulkan Compute，并在初始化时检查所需图像格式能力；显卡驱动不支持时会显示或记录具体错误。
