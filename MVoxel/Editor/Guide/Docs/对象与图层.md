# 对象与图层
## 创建和调整
1. 在层级空白处右键创建对象；点击对象即可选择。
2. 在检查器的“变换”中调整位置、旋转和缩放；体素旋转以 90 度为单位。
3. 在检查器底部点击“添加组件”，可搜索并添加相机、光照等组件。
选中模型时，黄色轮廓标示其可见边界；后方物体不会截断轮廓，前方遮挡物不显示穿透描边。

## 控制显示
场景工具栏的图层控制编辑视图；相机组件的图层遮罩控制相机画面，两者分别设置。
重叠模型的显示顺序由模型组件的排序图层和排序顺序决定。隐藏父对象也会隐藏子对象。
> 锁定对象可避免在场景中误选；在层级选择其他对象会解除原锁定。

## 调整面板布局

拖动面板标签或标题：贴近目标面板边缘时预览分区，拖到顶部标签栏或标题栏时合并为标签。正文区域不触发停靠，可自由移动窗口；松开鼠标时仅应用当前显示的预览。没有五向停靠方格。教程和图片预览保持独立浮动。

浮动窗口的边缘和底部带有阴影，便于与停靠面板区分。
