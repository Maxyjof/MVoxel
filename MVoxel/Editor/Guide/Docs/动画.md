# 动画

## 打开动画窗口

1. 在层级中选择对象，在检查器的“添加组件”中添加动画组件。
2. 点击组件中的“打开动画窗口”，或从“窗口 → 渲染 → 动画”打开。动画窗口默认关闭。
3. 动画窗口跟随当前选中对象；勾选“锁定动画对象”后，可以在查看子节点时保留当前动画根节点。

## 创建片段和预览

1. 在动画窗口点击“另存为动画片段…”，把片段保存到项目的 Assets/Animations 中，组件会引用该文件。
2. 调整当前帧、片段长度，以及需要显示的参数。启用“录制模式”可录制支持的编辑操作；完成后关闭录制。
3. 开启“播放”预览；根据需要设置循环和播放速度。负速度可反向播放。

“插入当前帧”目前会创建并写入片段文件，可能覆盖同名文件；使用前请备份已有片段。体素数据的右键菜单也提供插入关键帧入口。

## 调整过渡与保存

在关键帧所在帧的曲线区域，可调整过渡方向、右侧过渡方式及切线。片段文件和场景组件分别保存：调整后请保存项目，并检查片段引用是否正确。窗口提示没有动画组件时，先选择含动画组件的对象。
