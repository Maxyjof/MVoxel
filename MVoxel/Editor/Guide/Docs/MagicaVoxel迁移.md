# 从 MagicaVoxel 迁移

## 导入模型

1. 在项目菜单选择兼容导入，选择 `.vox` 文件。
2. 导入后在场景中选择模型，用调色盘和检查器继续编辑。
3. 按 Ctrl+S 保存项目。

## 常用操作

- 层级中的对象类似场景里的独立模型；对象可各自移动、旋转和缩放。
- 场景用于编辑，渲染窗口用于查看相机画面和导出图片。
- 相机的图层遮罩与场景窗口的图层显隐分别设置。

## 交换注意事项

- 推荐使用 `.mvmodel` 或 `.mvworld` 保存和交换 MVoxel 数据。
- `.vox`兼容导入会读取模型中的MATL材质并转换为项目共享材质资产，再按每个模型建立本地槽位映射；无法表达的参数会按兼容格式近似。`.vox`导出会先分析颜色与材质组合，超过兼容调色盘或存在不支持参数时显示损失摘要，确认后才写出；原生MVoxel格式用于无损保存与交换。
- `.vox` 有格式尺寸和颜色限制；这些限制不适用于 MVoxel 原生格式。
