# 从 MagicaVoxel 迁移
## 导入 .vox
新建项目：在欢迎界面选择“从 .vox 新建”，转换模型、实例和支持的材质。
已有项目：选择“项目 > 兼容导入（.vox / .qb / .schem）”，生成可编辑的原生模型资产；此入口不执行新建项目时的材质转换。
导入后检查位置、图层和材质，按 Ctrl+S 保存。格式不同，动画等数据可能无法保留。
支持 MAIN 根块子块长度为 -1（延续到文件末尾）的 MagicaVoxel 文件；无需先修改或重新导出原文件。内部数据块仍执行长度和边界检查，截断或损坏的数据会报告错误。
场景图中的文本平移和旋转会转换到 MVoxel 坐标系，以保留模型实例的位置和朝向。
导入按模型尺寸中心还原实例位置，并补偿原生资产裁剪空白边缘的偏移。修复前生成的项目不会自动重排，需要从原始 .vox 重新创建项目并检查结果。
坐标换算保留场景手性，避免单纯交换 Y/Z 轴导致建筑排列镜像；兼容导出使用对应的逆变换。
## 导出和交换
在“项目 > 导出 > 兼容导出”选择 .vox，阅读可能出现的兼容损失提示，并在目标软件中检查结果。
> 在 MVoxel 项目之间交换时优先使用原生格式并保留材质；.vox 的限制不适用于原生格式。
