# 资产与渲染

## 浏览和保存资产

底部“项目资产”按目录浏览项目内容，可搜索、筛选类型、调整图标大小；右键菜单提供创建和管理操作。场景中内嵌的体素可提取为模型文件。修改场景后按 Ctrl+S；资产编辑器中的保存按钮用于保存对应资产。

完整项目请使用“项目 → 另存项目为…”。“项目 → 导出”提供选中模型或场景体素的原生格式；交换到其他项目时同时保留所需材质定义。`.vox`、`.qb`、`.obj` 等用于兼容交换，各格式的能力和限制不同；VOX 见“MagicaVoxel 迁移”。

## 颜色和材质

调色盘颜色决定新画体素的基础色；画笔材质决定材质槽。模型组件维护本地槽位到共享材质资产的映射，不同模型可以共享资产或使用不同映射。修改画笔不改变已有体素；修改共享材质会影响引用它的模型。

在资产面板选择材质，调整参数后点击“保存材质”。删除材质或组件槽位前请阅读影响提示。失效引用不会自动重编号，应重新指定材质并检查场景。

玻璃和液体可调整不透明度、吸收色、吸收步长、折射率、粗糙度与散射。透明体的实际外观还受厚度和光照影响；材质设置不会自动把不透明体素改为半透明。提高雾化密度和体积散射可制作雾状介质；清澈玻璃可降低这些值。项目模板中的玻璃、水和云雾场景可用于观察效果。

## 配置与导出画面

1. 切换“渲染”标签；有相机对象时可在渲染窗口选择相机，没有相机时使用当前视角。
2. 从“窗口 → 渲染 → 渲染配置”打开常用设置，或进入项目设置调整完整渲染参数。光照、材质和相机变化会影响画面。
3. 路径追踪通过累积采样改善噪声；更多采样通常需要更长时间。实时渲染适合交互预览，路径追踪可用于观察透射、间接光和景深。
4. 使用渲染窗口的“导出…”或“项目 → 导出”输出 PNG、HDR 或全部相机 PNG；队列显示进度。批量任务按各相机的设置和图层遮罩输出。

路径追踪支持发光面直接采样；透明介质的折射、吸收和粗糙透射依赖材质与几何厚度。画面有噪声时可增加采样或调整降噪；性能开销也会随分辨率、采样和效果增加。

## 相机与后处理

相机图层遮罩独立于场景视图图层。相机组件可覆盖项目的后处理设置，包括环境遮蔽、辉光、色调映射、色彩调整、暗角及其他效果。覆盖关闭时使用项目设置；启用覆盖后，按各效果的启用状态和参数处理。HDR 线性输出不包含显示色后处理。

实时抗锯齿使用相机的采样选项，增加采样会提高开销。景深仅用于路径追踪；物理相机使用自身光圈和对焦距离，普通相机默认使用项目参数，也可在景深效果中启用独立参数，调整光圈半径和对焦距离。

## Volume 与探针

全局 Volume 可影响曝光、雾密度及辉光；隐藏的对象和禁用的组件不参与。局部 Volume 及部分环境参数尚未接入渲染，已有数据会保留。

通过“窗口 → 渲染 → 探针体积”打开探针窗口，可手动生成规则网格和高度渐变环境数据。当前不会采样场景光照或遮挡，也不会自动烘焙；关闭的探针不会用于渲染。

相机实时抗锯齿还提供 FXAA 边缘平滑，可调整边缘阈值和混合强度。FXAA 在后处理后的显示图上使用亚像素边缘采样，可能柔化细节；路径追踪仍使用累积采样。TAA 和 SMAA 尚未实现。隐藏父对象会使其子相机退出渲染相机列表。
