# 资产与渲染
## 管理资产
底部“项目资产”可浏览、搜索和右键管理文件。场景修改按 Ctrl+S；编辑材质等资产后，还要点击对应的保存按钮。
调色盘颜色和画笔材质用于新画的体素。共享材质修改后，引用它的模型都会受影响。
## 预览和导出图片
1. 切换“渲染”标签，选择相机；没有相机时使用当前视角。
2. 在“窗口 > 渲染 > 渲染配置”调整画面。实时渲染适合预览，路径追踪通过累积采样改善画面。
3. 在“太阳与阴影”选择渐进采样、半影重建或 PCSS 阴影贴图；悬停查看质量和回退说明。实时与路径追踪共用该选择。

模型组件的“镜像 X”沿模型局部 X 方向翻转体素，可以撤销；共享源资产不会被覆盖。当前请先把模型缩放恢复为 1 再镜像。
4. 点击渲染窗口的“导出…”保存图片；批量导出会使用各相机的设置和图层遮罩。
## 交换与备份
完整项目使用“项目 > 另存项目为…”。模型交换优先使用原生格式，并保留所需材质资产；兼容格式的能力可能不同。
> 相机遮罩与场景视图图层独立。画面有噪声时可增加采样，但会花更多时间。

## 继续阅读

[查看 VOX 导入和导出](MagicaVoxel迁移.md#导出和交换)

在资产面板空白处右键打开“创建”菜单，也可点顶部“新建”按钮打开同一个菜单，可创建文件夹、体素数据、场景、调色盘、材质、渲染预设、动画片段、时间轴、JavaScript 或 Lua 生成器，以及文本和 Markdown 文档；动画片段和时间轴可按类型筛选并在检查器预览；新资产保存在当前目录；右键文件夹也可在该文件夹中创建同样的资产。鼠标悬停在资产上会提示单击和双击分别会做什么。双击时间轴资产会在时间轴窗口打开，双击材质会在检查器里修改，双击场景会提示用“文件 > 打开场景”切换，其余类型用系统程序打开。右键文件还可创建副本、重命名、移动到文件夹或删除；副本会生成独立的资源元数据，并直接进入重命名，移动时从下拉列表选择 Assets 下的目标目录。正在编辑空间中打开的资产不允许删除，需先返回场景。

双击原生体素数据、右键选择“打开”，或点击其检查器中的“编辑体素资产”，进入独立编辑空间，Ctrl+S 保存资产，顶栏的“保存资产”按钮等价于 Ctrl+S，没有未保存修改时不可用，旁边显示当前编辑空间的体素总数与对象数；顶栏“另存副本”会先保存再复制一份资产并切换到副本继续编辑，适合做设计分叉，“定位”可让资产面板跳回当前资产并选中；点击层级面板顶部的“返回场景”并选择保存或放弃修改；隐藏层级面板时入口位于场景窗口顶部；场景中仍引用该资产的对象随之刷新。单模型保存时保留体素相对资产原点的位置。原生资产的内嵌材质槽位在编辑空间中可供绘制，绑定项目材质后保存会写入材质定义；场景实例未单独绑定的槽位使用资产内嵌材质。状态栏分别提示资产和原场景的保存状态；场景和体素资产各自使用独立的撤销历史。多对象文档保存对象名称、原点、体素和材质槽；不支持保存场景层级、额外组件和旋转缩放，保存前需还原这些属性。双击 VOX、QB 或 SCHEM 会先在同目录导入一个独立的原生体素资产，再进入编辑空间；原交换文件保留。含多个实例的 VOX 会转为多对象文档，保留实例名称与体素位置，图层和隐藏状态不随之导入。

返回场景时会恢复进入前的视角，并重新读取引用对象的体素数量和资产内嵌材质。
多对象原生资产采用流式读写，保存时回读校验后再替换原文件。
保存前会校验片段标识唯一、标识与名称长度以及体素数量上限，避免写出自身无法读回的资产；读取时会检查对象标识、记录长度和重复体素坐标，畸形编码与截断文件统一按文件损坏提示。
如果读取失败，原场景的内存数据会保留，场景覆盖保存会暂停，直到修复资产并重新打开。
在同一编辑会话中撤销或重做场景操作后，仍引用已编辑体素资产的对象会重新读取当前资产内容。

单模型原生资产保存体素和材质，不保存编辑空间对象的名称、原点、层级或额外组件；修改这些属性后需先还原，才能保存。资产名称可在资产面板重命名。

右键创建资产后会直接进入重命名：输入框只编辑主名，扩展名固定保留，复合扩展名如 .mvanim.json 也整体保留；新建时若开着搜索或类型筛选，会先回到该资产所在目录并清空筛选，保证新资产可见。

右键原生体素资产选择“添加引用到场景”，可创建引用该资产的模型对象；多对象资产会按片段创建多个引用对象。资产编辑保存后，已有片段引用会在返回场景时刷新；没有旋转、缩放或镜像的引用会跟随片段位置变化并保留自身偏移，其他场景在打开时同步。旧场景若没有记录来源原点，会先以当前资产原点建立基线。片段增删暂不自动调整场景对象。若引用的片段已删除，其他片段仍会刷新，缺失片段保留当前显示并阻止场景覆盖保存，需修复资产后重新打开。

编辑多对象资产时，若项目内场景或预制体仍引用某个被删除的片段，保存会提示先还原片段或处理这些引用；当前场景使用未保存的内存内容检查。
个别引用因旋转、缩放或镜像无法同步位置时，其他可同步的引用仍会刷新；场景保存会受到保护并提示处理。
刷新多对象资产引用时，编辑器会按片段标识查找对象，避免为每个引用重复扫描整份对象列表。
在独立编辑空间中通过资产面板移动或重命名当前资产后，保存会使用新路径。
MVoxel MCP 用 `asset.list` 浏览资产（`kind` 支持枚举名或创建简写），用 `asset.create`、`asset.createFolder`、`asset.duplicate`、`asset.rename`、`asset.move`、`asset.delete` 完成与右键菜单相同的创建和管理，`asset.create` 带 `open=true` 时创建后直接进入体素编辑空间或生成器面板，正在编辑的资产不能删除；引用会随改名与移动一起更新，`asset.references` 可查询引用位置，`asset.info` 读取体素数量与包围盒；`asset.openStage` 打开编辑空间，`asset.stage.status` 读取当前编辑的资产与脏标记，`asset.stage.save` 保存，`asset.stage.saveAsCopy` 另存副本并切换编辑，`asset.returnScene` 返回场景，有未保存修改时需带 `save=true` 或 `discard=true`。
打开资产编辑空间时，场景视角会对准模型包围盒的中心；同一资产再次进入会沿用上次离开时的取景，新建资产才重新对准，切换或关闭项目后重置。
在编辑空间里尝试退出编辑器、关闭项目或切换项目时，会先弹出保存或放弃的选择；没有未保存修改时直接返回原场景。
进入编辑空间时资产面板会自动定位到该资产，并在平铺中把类型标签标为“编辑中”；返回场景后标记消失，编辑期间在面板里重命名或移动到别的目录也会跟着更新。

双击预制体或预制体变体可进入独立编辑空间，保存后可返回场景；变体保留其基础资产关系及覆盖。返回场景时会更新当前场景实例中未覆盖的对象属性和非体素组件；未修改的体素组件也会更新；有覆盖或无法安全读取时会保留原数据。可同步的新增普通子对象也会加入；资产中删除的普通叶对象仅在没有覆盖、子对象或组件引用时同步删除；其他场景打开时会尝试合并预制体修订中可安全处理的部分；外层同步会保护已有嵌套实例，嵌套实例按自身来源尝试同步；未完成的体素和结构变化会保留待处理状态。

场景窗口的地面网格随视角和缩放平滑切换疏密，远景保留连续的层级主线参照并通过屏幕像素覆盖率抗锯齿淡出，体素描边按屏幕像素控制宽度。

预制体的对象图层和组件启用状态会随资产保存与实例化。将实例应用到预制体时会保留预制体身份和修订基线，并尝试同步其他实例；来源尚未同步或含嵌套预制体时，请先处理来源更新或在独立编辑空间修改。

预制体变体记录基础资产的修订；基础资产保存新修订后，变体可识别更新并保留已记录的覆盖；拉取时保留修订基线，并尝试同步场景实例。

右键预制体选择“实例化到场景”会先读取其模型数据；引用缺失时保留当前场景并显示原因；还原实例也会先读取模型，成功后替换对应对象。

从层级对象生成预制体时，会将对象当前的内嵌体素修改写入新资产。

预制体实例的检查器会提示尚未合并的来源修订，并提供“尝试同步”操作；不能安全合并的内容继续保留。嵌套部分没有发生变化时，不会单独阻止外层修订完成同步。
预制体根对象未被实例单独改名时，来源名称的修改也会同步；实例自行修改的名称会保留。
没有组件或变换覆盖的体素子对象可同步来源的格位置平移；旋转、缩放等其他变换变化仍保留待处理状态。
合并预制体修订时，新增、删除或更新对象所需的体素读取若失败，当前实例会恢复到合并前的场景状态；其他实例仍可继续处理。实例覆盖和不能安全合并的结构仍保留待处理状态。
实例合并只为当前子树保存对象快照，场景中其他对象无需重复序列化。
体素坐标平移超出原生坐标范围时会中止该操作，避免坐标回绕到另一侧。

在资产编辑空间中移动或重命名其他资产时，原场景的相关引用也会跟随更新；返回场景后保存这些修改。

资产删除确认会列出当前编辑空间及原场景中尚未保存的引用；正在编辑的资产也会显示在提示中。
