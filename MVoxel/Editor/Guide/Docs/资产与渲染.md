# 资产与渲染

材质槽位属于模型组件，不属于材质资产。每个模型组件维护自己的“本地槽位编号 → 共享材质资产”映射；不同组件可以用相同编号引用不同材质，也可以共享同一个材质资产。材质检查器只编辑材质资产参数，并显示当前场景的引用模型；点击引用可定位对象。删除材质资产或组件槽位前会提示影响，确认删除后保留失效引用与体素编号，暂时使用默认外观，不自动重编号。

调色盘中的颜色是画笔将要绘制的方块基础色，画笔材质决定新方块引用哪个材质槽位；两者分别控制基础颜色和材质外观。改动画笔不会重绘已有方块。若只想让模型的一部分方块使用另一材质，请擦除那些方块，再选择目标颜色和材质画笔重新绘制；编辑材质资产则会影响所有引用其槽位的方块。调色盘里的“编辑项目色板”只管理基础颜色，不编辑材质参数。

## 资产

- 底部资产窗口用于浏览项目文件；项目按窗口宽度自动换行，内容较多时可向下滚动。右键空白处可创建文件夹。
- 绘制的体素可以内嵌在场景中；右键“内嵌数据”可提取为模型文件。
- 推荐使用 MVoxel 原生格式；`.vox` 用于兼容交换。

## 渲染与保存

- 切换到“渲染”，选择相机，再通过“导出”保存图片。
- 场景本地光源可照亮朝向光源的表面；启用阴影时，超出光源范围或背向光源的表面不会产生直接光。
- “发光面直接采样”让路径追踪主动采样暴露的不透明发光面，并与表面反弹命中通过 MIS 合并。关闭时只保留射线命中发光，可用同一相机和采样设置比较收敛。实时模式仍只显示体素自身发光。
- “光源树重要性采样”在超过 32 个发光面时，按灯面功率和接收点距离分配采样概率；少量面直接均匀采样。关闭此开关可比较均匀采样。树不会排除暗灯，几何遮挡仍由阴影射线计算。
- 直接采样不穿越透明介质，透明体的折射与吸收由路径反弹处理；与非空邻格接触的面不进入直接采样目录。手动启用几何 LOD 或体素预算时，目录停用，以免采样不属于当前几何的灯面。不会自动降低分辨率或体素精度。
- 发光贡献仍受辐射度截断影响；直接采样和反弹命中使用相同的发光值。“太阳直接光采样”仅控制路径追踪中的太阳直接光，不控制本地灯或自发光体素。使用发光照明时选择支持该功能的 Compute 渲染路径。
- 性能分析面板显示发光面数量和最近一次索引同步耗时；该数值为 CPU 提取、排序、打包与上传耗时，不代表 GPU 帧时间。
- 光源树的面集合未变时更新现有拓扑；面集合变化时重建。GPU 只上传合并后的脏数据范围，范围过多或缓冲大小变化时整批上传。面数量、树节点数量和同步耗时可在性能分析面板查看。
- Ctrl+S 保存项目；场景名前的 * 表示场景尚未保存。
- 修改材质后，路径追踪会重新开始累积，避免新旧材质照明混合。切换可见世界时会重建砖驻留数据。
- 路径追踪采用 GGX 镜面与余弦漫反射的混合采样；路径权重按完整表面响应和混合概率计算。

玻璃等半透明材质在路径追踪中根据材质折射率计算入射和出射方向，并按介质厚度吸收光线。

画面比例与分辨率管理窗口中，可使用每行的上下箭头调整预设顺序；悬停箭头可查看操作提示。

路径追踪沿光线穿过连续的同材质半透明体素，并在实际出口计算折射；球体、薄片及不规则形状的透射会随实际厚度变化。

半透明物体相接时，路径追踪按两侧材质的折射率处理界面；实时渲染也会叠加杯壁后面的透明液体。默认模板的可乐液面距杯沿一格。

默认模板的纸杯和可乐是独立对象，可乐位于纸杯的子层级，可分别选择和编辑。

在资产面板选择 `.material` 材质，可调整半透明不透明度、体积散射、吸收步长、吸收色、折射率、粗糙度和镜面强度，点击“保存材质”生效。不透明度可跟随体素 Alpha 或单独覆盖；散射越低越清澈，透明材质的实际吸收还取决于厚度。材质参数作用于使用该槽位的半透明体素；设置不会自动把不透明体素改成半透明。

制作雾状介质时，可在半透明材质中提高“雾化密度”和“体积散射”，并单独选择散射色；不透明度及介质厚度也会影响浓淡。清澈玻璃可将雾化密度与体积散射设为 0。修改后点击“保存材质”。

渲染时会连续追踪相邻同材质半透明体素，不把它们的内部格面当成空气界面；不同材质接触处按各自的折射率处理。

新项目预览和 MCP 截图默认累积 128 个样本；模板按场景复杂度设置为 128 或更高，采样越多通常噪声越少，但收敛时间也越长。已有项目的设置不会自动更改。

路径追踪的像素抖动按已累积的样本编号推进，即使每帧采集多个样本也不会重复使用相邻帧的抖动位置。复杂间接光和小面积光源仍可能在数百样本后残留噪声，可继续增加采样或调整降噪强度。

路径降噪使用累积亮度方差调整邻域权重，同时保留法线和深度边缘约束；不会降低渲染分辨率或体素精度。降噪强度仍可手动调节。

路径追踪对粗糙透明介质采用透射方向扩散近似：粗糙度越高，背景越模糊，低采样时噪声可能更明显。可用“玻璃透射对照”模板比较透明、有色与毛玻璃。

有色玻璃的色偏由吸收颜色、吸收步长、不透明度和厚度共同决定；单格薄片需要更明显的吸收才能展示染色效果。模板的琥珀玻璃使用吸收色 RGB(250,155,45)、吸收步长 6、不透明度 0.85、体积散射 0，保持透射清晰。

连续的同材质透明体素作为一个介质穿行；透明体直接接触不透明表面时，在接触面着色，不在两者之间虚构空气层。
接触面的不透明体素直接使用介质穿行时记录的命中结果，避免再次求交时在相邻体素边界选错表面。
射线从体素内部出发时，优先处理包含起点的体素，避免共面出口和相邻入口的浮点距离竞争产生假折射界面和周期性黑线。

材质与渲染模板中的“康奈尔盒光照”和“玻璃球与棋盘”分别用于观察间接光、色彩溢出、反射与透射。它们是体素场景，几何和材质不等同于网络参考图，不能作为逐像素一致性验证。
