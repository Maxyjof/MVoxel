# 资产与渲染

## 资产

- 底部资产窗口用于浏览项目文件；项目按窗口宽度自动换行，内容较多时可向下滚动。右键空白处可创建文件夹。
- 绘制的体素可以内嵌在场景中；右键“内嵌数据”可提取为模型文件。
- 推荐使用 MVoxel 原生格式；`.vox` 用于兼容交换。

## 渲染与保存

- 切换到“渲染”，选择相机，再通过“导出”保存图片。
- 场景本地光源可照亮朝向光源的表面；启用阴影时，超出光源范围或背向光源的表面不会产生直接光。
- “发光面直接采样”让路径追踪主动采样暴露的不透明发光面，并与表面反弹命中通过 MIS 合并。关闭时只保留射线命中发光，可用同一相机和采样设置比较收敛。实时模式仍只显示体素自身发光。
- 直接采样不穿越透明介质，透明体的折射与吸收由路径反弹处理；与非空邻格接触的面不进入直接采样目录。手动启用几何 LOD 或体素预算时，目录停用，以免采样不属于当前几何的灯面。不会自动降低分辨率或体素精度。
- 发光贡献仍受辐射度截断影响；直接采样和反弹命中使用相同的发光值。“太阳直接光采样”仅控制路径追踪中的太阳直接光，不控制本地灯或自发光体素。使用发光照明时选择支持该功能的 Compute 渲染路径。
- 性能分析面板显示发光面数量和最近一次索引同步耗时；该数值为 CPU 提取、排序、打包与上传耗时，不代表 GPU 帧时间。
- Ctrl+S 保存项目；场景名前的 * 表示场景尚未保存。
- 修改材质后，路径追踪会重新开始累积，避免新旧材质照明混合。切换可见世界时会重建砖驻留数据。
- 路径追踪采用 GGX 镜面与余弦漫反射的混合采样；路径权重按完整表面响应和混合概率计算。
