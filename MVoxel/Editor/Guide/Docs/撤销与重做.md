# 撤销与重做
## 撤回一步
按 Ctrl+Z 撤销；按 Ctrl+Y 或 Ctrl+Shift+Z 重做。“编辑”菜单显示下一步操作名称。
绘制、对象和组件编辑、资产操作及设置等使用编辑历史。连续描画或拖动通常合并为一步；新编辑会清空重做分支。
## 遇到确认窗口
删除、覆盖或大量修改可能要求确认。检查受影响的文件和对象，选择“确认执行”或“取消”。文件被外部修改后，编辑器可能拒绝覆盖，请先处理冲突。
## 保存与关闭
保存不会清空当前历史，但关闭或切换项目后会建立新历史。撤销场景修改后仍需保存。
> 文本输入框优先撤销自己的文字；编辑器无法撤销外部程序的操作。
