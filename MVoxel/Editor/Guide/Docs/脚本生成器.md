# 脚本生成器
## 用内置脚本试一试
1. 打开项目并选择目标模型，打开生成器窗口。
2. 点击“内置脚本”，创建可编辑的项目副本，例如“噪声丘陵”。
3. 检查目标和参数，点击运行。结果作为一步应用，可用 Ctrl+Z 撤销；运行失败不会应用结果。
## 编辑脚本
可新建 JavaScript 或 Lua 生成器，参考新建时提供的示例。修改源码后点击“重新读取声明”或保存，再检查参数并运行。
切换脚本前请保存草稿，或选择“恢复已保存版本”放弃草稿。
> 脚本接口和限制较多，完整说明保留在程序文档的“参考资料/脚本生成器.md”。
