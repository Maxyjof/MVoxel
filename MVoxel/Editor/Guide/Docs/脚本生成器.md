# 脚本生成器

## 创建与运行

打开项目后，在生成器窗口新建 JavaScript 或 Lua 生成器；编辑源码并保存为项目资产。运行时生成结果先暂存，再作为一个可撤销步骤应用到当前对象。运行失败不会应用暂存结果。
源码尚未保存时，先保存或点击“恢复已保存版本”，再打开其他生成器或新建脚本；恢复操作会放弃当前源码草稿。
关闭项目、切换项目或退出编辑器时，未保存源码会包含在保存提示中；选择保存会保存源码，失败时不会继续关闭。
项目切换完成后，生成器面板会清除旧项目的脚本和参数；请从新项目重新打开生成器。

点击“内置脚本”可创建可编辑的项目副本：“噪声丘陵”按种子、尺度和高度生成地形；“颜色斑驳”对已有体素添加确定性的明暗变化；“按颜色替换”替换指定 RGB 颜色。两种颜色脚本均保留 Alpha、材质槽和标志。“保留表面”清除六个相邻位置都有体素的内部格，保留区域边界和其他表面格；它按运行前状态判断，不受扫描顺序影响。模板均可设置目标对象局部坐标中的中心位置（丘陵的 Y 是底部高度）；运行前请确认目标对象及参数。已创建的旧模板副本不会自动更改。

## 声明与参数

源码调用一次 `generator.define`，声明 `name`、`bounds`（`min` 和 `max` 各为三个坐标）、可选 `parameters` 和 `run(ctx, p)`。新建时提供相应语言的示例。参数类型为 `int`、`float`、`bool`、`string`、`color`；参数的 `id` 用于在 `p` 中读取，`label` 用于界面，数值参数可声明 `min`、`max` 和 `default`。整数参数使用 32 位范围。
`parameters` 应为数组；Lua 使用从 1 开始连续编号的表，空参数可省略或使用空表。格式错误会在读取声明时提示。

## 体素接口

`ctx` 提供以下接口，长方体两角均包含在内，坐标与半径须为整数：
坐标、半径及体素数据中的数值字段必须提供有限数字；缺失或其他类型不会自动转换为零。可选材质槽和标志省略时默认为零。
颜色数组须包含三个或四个有限数字通道；数字通道的小数部分会向零截断。
普通绘制接口的打包颜色不超过 `0xFFFFFFFF`，负数或空值表示擦除；为兼容 RGB 输入，普通绘制将打包颜色中的零 Alpha 当作不透明。如需原样写入零 Alpha，请使用 `setVoxelData`。

- `setVoxel(x, y, z, color, slot, flags)`：设置单格。
- `getVoxel(x, y, z)`：读取包围盒内的体素，返回 `{ color, slot, flags }`；空格返回 JavaScript `null` 或 Lua `nil`。颜色为 `0xAARRGGBB` 数字。优先读取本次运行的暂存结果，包括擦除，再读取目标对象。
- `setVoxelData(x, y, z, voxel)`：写入 `getVoxel` 返回的数据，保留完整 RGBA、材质槽与标志；传入 `null`（Lua 为 `nil`）擦除。适合复制体素数据。
- `fillBox(x0, y0, z0, x1, y1, z1, color, slot, flags)`：填充长方体。
- `fillSphere(x, y, z, radius, color, slot, flags)`：填充球体。
- `eraseVoxel(x, y, z)`、`clearBox(x0, y0, z0, x1, y1, z1)`：擦除。
- `replaceColor(x0, y0, z0, x1, y1, z1, oldColor, newColor, slot, flags)`：在区域内替换匹配的 RGB 颜色，并读取同次运行中已暂存的结果。省略或传入 0 的材质槽与标志保留原值。

颜色支持 `0xRRGGBB` 数字、`#RGB` / `#RRGGBB` / `#AARRGGBB` 字符串和 `[r,g,b]` / `[r,g,b,a]` 数组（Lua 使用表）。空颜色表示擦除；材质槽默认为 0，标志默认为 0。标志接受完整的 0–255 字节，已定义位为 1（半透明）和 2（自发光），其余位在复制时保留。写入不得超出声明的包围盒；单轴跨度最多 512，坐标绝对值最多 1000000。单次暂存最多 2000000 个不同坐标，重复写入以最后结果为准；单次区域操作也有遍历预算。

## 限制与排错

生成器声明和运行分别受执行时间限制，批量区域遍历也会检查运行时限；超时不会应用暂存结果。出现错误时查看窗口底部信息并修正源码；Lua 声明表不能循环引用或嵌套过深。
修改源码后，先点击“重新读取声明”或保存源码，再检查更新后的参数并运行；尚未重新解析的源码不能运行。
重新解析同一生成器时，同类型参数保留已填值并按新范围约束；参数类型变化或切换到其他生成器时使用新声明的默认值。
