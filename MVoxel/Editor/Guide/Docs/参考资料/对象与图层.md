# 对象与图层

## 创建和选择对象

- 在层级空白处右键创建对象；右键对象可查看管理操作。
- 检查器的“变换”可调整位置、旋转和缩放。体素旋转以 90 度为单位。
- 模型可以重叠；重叠位置按模型组件的排序图层和排序顺序显示。

## 图层与可见性

- 场景工具栏的“图层”只控制场景视图。
- 相机有独立的图层遮罩，用于控制相机画面。

- 每个对象固定包含一个变换组件。相机和光照组件在同一对象上不能重复添加。

- 锁定对象后，场景中不能选择其他对象；在层级选择其他对象会自动解除原锁定。通过停靠面板右上角的菜单可添加检查器标签，各检查器可独立锁定对象。

- 在停靠面板右上角的三点菜单中，按常规、渲染或工具分类添加窗口标签；顶部“窗口”菜单用于打开或聚焦已有窗口。

- 停靠面板即使只有一个窗口，也会显示窗口名称标签和右侧菜单。

使用选择工具点击体素时会选中它所属的对象，场景视图以高亮轮廓显示该对象；在层级中选择模型也会显示轮廓。

层级中隐藏的对象（含被隐藏父对象或图层影响的对象）名称会变淡；选中模型时显示可见外轮廓。

场景中点击对象时，层级会展开其父级并定位选中项；选中父对象时，场景轮廓包括可见的子对象。


## 组件

检查器底部的“添加组件”菜单按体素、视图、渲染和动画分类列出可添加的组件。相机的后处理覆盖选项可在相机组件中修改并保存。

添加组件菜单支持按名称、分类或类型 ID 搜索；不可添加的组件会变灰，悬停可查看原因。插件组件也可搜索。

相机、光照、Volume、探针和动画组件的“恢复默认”会重置本版本认识的参数；编辑时保留数据中未识别的对象字段。移除后处理效果仍会删除该效果。

### 曲线渲染器

`mvoxel.curverenderer` 用一条三次贝塞尔曲线生成体素，参数和曲线都可随时修改，生成结果即时重建。

- 进入曲线编辑后，控制点改位置，入/出切线改弯曲角度，朝向手柄改截面旋转；双击曲线插入点，Delete 删除选中点。
- 切线联动方式：自动按相邻点推算、对齐保持反向、镜像保持等长反向、自由互不影响；手动拖切线会把该点切成自由。
- 生成参数：截面形状（方块管、圆管、珠链、十字管）、半径、采样间距、曲线细分、颜色、自发光、材质槽、排序图层与顺序。
- 生成的体素保存在组件的隐藏负载里，不显示在检查器，不进入绘制模式；单对象上限 60 万格，超出后截断并提示。
- 曲线渲染器与模型组件互斥，同一个对象只能有一个体素来源。

### 树生成器

`mvoxel.treegenerator` 用一组参数程序化生成一棵树，参数改动不会自动生效，点「生成体素」才替换。

- 风格：阔叶树、针叶树、灌木、棕榈、垂柳、樱花树、枯树；切换风格会套用推荐参数。
- 参数分组：树干（高度、半径、倾斜、弯曲、收缩、树根）、枝条（数量、长度、粗细、上扬角、下垂、分叉层数）、树冠（形态、起始、半径、高度、叶片密度、叶团大小）、颜色与排序。
- 生成的体素保存在组件隐藏负载里，逐格保存颜色；参数改了但没点生成时，旧树原样保留，重新打开也不变。
- 「实例化为体素模型」会移除树生成器并添加模型组件，之后可以进入绘制模式；实例化不可逆，只能撤销恢复。
- 与模型组件、曲线渲染器互斥；单对象上限 60 万格。

### 程序化体素的 MCP 命令

`curve.get/set/generate/create`、`tree.get/set/generate/create`、`tree.instantiate` 与 `scene.components.list` 已登记在编辑器命令总线里，MCP 用 `editor.commands` 发现、`editor.exec` 调用。

## 组件数据

曲线的控制点、生成参数、隐藏负载与参数指纹在同一个组件 JSON 中，随场景文件保存。
