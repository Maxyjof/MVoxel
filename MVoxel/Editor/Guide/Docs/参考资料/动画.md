# 动画

## 打开动画窗口

1. 在层级中选择对象，在检查器的“添加组件”中添加动画组件。
2. 点击组件中的“打开动画窗口”，或从“窗口 → 渲染 → 动画”打开。动画窗口默认关闭。
3. 动画窗口跟随当前选中对象；勾选“锁定动画对象”后，可以在查看子节点时保留当前动画根节点。

## 创建片段和预览

1. 在动画窗口点击“另存为动画片段…”，把片段保存到项目的 Assets/Animations 中，组件会引用该文件。
2. 调整当前帧、片段长度，以及需要显示的参数。启用“录制模式”可录制支持的编辑操作；完成后关闭录制。
3. 开启“播放”预览；根据需要设置循环和播放速度。负速度可反向播放。

“插入当前帧”目前会创建并写入片段文件，可能覆盖同名文件；使用前请备份已有片段。体素数据的右键菜单也提供插入关键帧入口。

## 调整过渡与保存

在关键帧所在帧的曲线区域，可调整过渡方向、右侧过渡方式及切线。片段文件和场景组件分别保存：调整后请保存项目，并检查片段引用是否正确。窗口提示没有动画组件时，先选择含动画组件的对象。

## 编排时间轴

1. 从“窗口 → 渲染 → 时间轴”打开时间轴窗口。空时间轴默认 30 帧/秒、10 秒，顶部可调整帧率、总时长和总帧数；修改帧率时按当前秒数换算总帧数。
2. 轨道分三类：对象启用区间、动画片段编排（片段、起止帧、速度、循环）和条件事件。
3. 播放、暂停和拖动播放头会同步预览天气与对象轨道；暂停或关闭窗口后保持当前帧。仅播放或拖动播放头不会把时间轴标记为已修改。
4. 临时时间轴第一次保存时选择 Assets 内的位置；“另存为…”另存为新资产，名称取文件名。
5. 有未保存修改时，关闭窗口、切换或重载时间轴、关闭或切换项目、退出编辑器都会询问，可选“保存”“另存为…”或“不保存”。

## 导出视频

在渲染窗口右上角打开“导出…”，把导出类型切换为“视频”，选择时间轴和输出帧率后指定 MP4 路径。输出为 H.264，宽和高必须为偶数，目标文件不能已存在。程序先准备可取消的体素与动画快照，再逐帧渲染；帧全部完成后在后台编码，成片只在编码成功后提交到目标路径。编码失败或取消会删除半成品并保留帧目录，全部成功后自动清理中间帧。
