# 从 MagicaVoxel 迁移

## 选择导入入口

- 欢迎界面“从 .vox 新建”创建新项目：将文件中的模型和实例转换为项目场景对象，并把支持的 MATL 材质转换为共享材质资产；材质外观可能需要调整。
- 已打开项目时，在“项目 → 兼容导入（.vox / .qb / .schem）”中选择文件。该入口读取体素并生成原生模型资产，用于继续编辑；它不会执行上述新建项目的材质转换流程。

导入后检查对象位置、图层、材质和外观，再按 Ctrl+S 保存项目。不同格式的特性不完全相同，动画及其他无法表示的数据不能保证保留。

## 在 MVoxel 中工作

层级管理独立对象，场景视图用于编辑，渲染视图用于查看画面。场景图层显隐与相机的图层遮罩分别设置。模型组件中的材质槽关联项目共享材质资产；修改资产会影响所有引用它的模型。

## 交换与导出

优先使用原生 `.mvmodel` / `.mvworld` 交换体素数据；材质资产和完整项目场景需要一并保留，完整项目可使用“另存项目为…”。

“项目 → 导出 → 兼容导出”提供 `.vox`。导出会分析颜色与材质的兼容损失，必要时显示摘要供确认；格式的尺寸、颜色和材质表达限制不适用于原生格式。导出后请在目标软件中检查结果。
