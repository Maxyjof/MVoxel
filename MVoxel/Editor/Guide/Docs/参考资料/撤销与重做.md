# 撤销与重做

## 操作入口

- Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做。“编辑”菜单显示当前方案绑定，悬停可查看操作名称；没有对应记录时不可点击。
- 设置 → 快捷键方案可以修改撤销、重做及备用重做绑定。修饰键必须完全匹配，Ctrl+Shift+Z 不会误触 Ctrl+Z。
- 撤销和重做都支持按住连续执行，延迟与间隔由设置中的撤回选项控制。文本输入框优先使用自己的文字撤销，不会同时回退模型。
- 连续描画、滑条拖动、手柄拖动和一次平滑聚焦合并为一个步骤；新修改会清空重做分支，无变化的生成器运行不会清空历史。

## 共用历史的编辑内容

- 体素描画、擦除、填充、直线和长方体、换色、模型移动/旋转/缩放、模型数据引用切换、生成器运行。
- 对象创建、层级与排序、名称、显隐、锁定、变换、组件添加/移除/排序/属性，相机与灯光，图层及相机遮罩。
- 预制体创建、变体、应用、还原及覆盖项；恢复时保留对象 ID、预制体链接和未知插件组件数据。
- 原生与兼容体素导入、网格导入、Minecraft 后台导入、工作模型替换；场景和实际新增资产一起恢复，重做使用记录的导入结果。
- 资产新建、文件夹创建、删除、移动、重命名、材质/生成器/调色盘/预制体/渲染预设写入，及关联的 .meta 与自动更新的资产引用。
- 编辑器与项目设置、快捷键方案、渲染参数、主题、调色盘、未保存材质和生成器草稿、环境贴图、工具与笔刷、选择、视角、窗口和停靠布局。

## 删除、覆盖与大批量操作

- 会删除或覆盖文件的方向（包括撤销资产导入）、移除场景对象、替换已有模型，以及单步达到 100,000 次体素格修改时，显示阻塞弹窗。
- 弹窗说明操作方向、名称、受影响文件或对象数量。点击“确认执行”才修改数据；点击“取消”或按 Esc 不执行，也不移动历史栈。
- 确认期间停止快捷键连发；关闭弹窗后必须松开原快捷键才恢复响应。文件列表较长时可滚动查看，弹窗尺寸随字体、内容和可用屏幕大小计算。
- 若文件在记录之后又被保存或外部修改，会拒绝覆盖并保留历史。先处理该文件的后续修改再重试；确认弹窗不授权覆盖未记录的文件版本。

## 保存与会话边界

- 历史属于当前打开的编辑会话。保存项目不会清空历史；关闭/切换项目、重新启动后建立新的历史。项目打开关闭、退出、导出任务和运行时日志不作为数据编辑回放。
- 撤销场景修改后仍需保存项目；配置按自动保存机制持久化。资产文件操作直接作用于磁盘，撤销时恢复该操作记录的文件版本。
- 文件前后版本使用临时磁盘副本保存，大模型不会为文件历史整体读入内存；体素历史继续按逐格差异保存，不降低原生容量、模型精度或渲染分辨率。
- 放弃重做分支、关闭会话时仅释放本次历史拥有的临时副本，不清理用户资产、恢复数据或诊断日志。
- 插件通过编辑器入口执行的受管资产修改和组件数据编辑遵循同一历史；外部程序或插件自身的网络请求、进程和其他外部副作用无法通过编辑器历史回放。
