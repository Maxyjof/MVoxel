# MVoxel editor icons

The editor uses regular-weight SVG icons from Microsoft's Fluent UI System Icons.
The source package is open source under the MIT license:

- Repository: https://github.com/microsoft/fluentui-system-icons
- Iconography guidance: https://fluent2.microsoft.design/iconography

The adjacent PNG files are local rasterizations of the downloaded SVG files for
the ImGui toolbar and panel buttons. The icon artwork is not modified.
